# Exploratory Data Analysis – Project Report

## 1. Introduction
Exploratory Data Analysis (EDA) is used to understand a dataset through statistical methods and visualizations. This project analyzes sales data to discover useful patterns and trends.

## 2. Objective
The main objective is to analyze sales performance across products, categories, regions, quantities, prices, discounts, and time.

## 3. Dataset
The dataset contains order information including Order ID, Order Date, Region, Category, Product, Quantity, Unit Price, Discount, and Sales.

## 4. Data Preprocessing
The raw data was checked for missing values and duplicate records. Missing categorical values were replaced using the mode, missing numerical values were handled using the median, and duplicate rows were removed.

## 5. Exploratory Analysis
Statistical summaries and visualizations were used to understand distributions, category performance, regional performance, monthly trends, variable relationships, and potential outliers.

## 6. Key Findings
- Category-wise sales can be compared to identify major contributors.
- Region-wise analysis shows differences in sales performance.
- Monthly analysis reveals changes in sales over time.
- Quantity and sales can be studied using scatter plots and correlation analysis.
- Box plots help identify unusual observations.

## 7. Conclusion
The project demonstrates how EDA can transform raw sales records into understandable insights. The analysis can be extended in the future with predictive modeling and dashboards.
