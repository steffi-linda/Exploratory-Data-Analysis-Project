# Exploratory Data Analysis (EDA) – Sales Data

## Project Overview
This project performs Exploratory Data Analysis on a sales dataset to identify patterns, trends, correlations, and important business insights.

## Objectives
- Understand the structure of the dataset
- Detect and handle missing values
- Identify duplicate records
- Generate statistical summaries
- Visualize sales patterns
- Analyze category and regional performance
- Study correlations between numerical variables
- Detect potential outliers
- Present meaningful conclusions

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files
- `EDA_Sales_Analysis.ipynb` – Complete analysis notebook
- `raw_sales_dataset.csv` – Dataset used for analysis
- `README.md` – Project documentation

## How to Run
1. Open Anaconda Prompt.
2. Run `jupyter notebook`.
3. Open `EDA_Sales_Analysis.ipynb`.
4. Run the cells from top to bottom.
5. Keep `raw_sales_dataset.csv` in the same folder as the notebook.

## Visualizations
The notebook includes:
- Sales distribution histogram
- Category-wise sales bar chart
- Region-wise sales bar chart
- Monthly sales trend
- Quantity box plot
- Sales vs Quantity scatter plot
- Correlation heatmap
- Sales and quantity outlier plots

## Conclusion
EDA helps convert raw sales data into useful information. The analysis identifies sales trends, high-performing categories and regions, relationships between variables, and unusual observations.
